# 기존 등록 테스트 스크립트

커밋 `245c9fa4b8b9d2bc562a0023a5bc738dfac88cd9`의 `test-runbooks/*.sh` 58개를 그대로 복원했습니다. `catalog.json`에 종류·원본 경로·SHA-256을 등록하고 `config.ERROR_RULES`로 장애별 실행 후보를 연결합니다.

58개 스크립트는 UTC 시각, 로그 레벨, 호스트·서비스·컴포넌트, `execution_mode=simulation`을 포함한 운영형 로그를 단계별로 출력하고 단계 사이에 짧게 대기합니다. 진단 스크립트는 기존 `TEST_*` 표식을 유지하며 `check_disk_usage.sh`만 실행 컨테이너의 `df`를 읽습니다. 실제 대상 서비스를 변경하거나 복구를 측정하는 스크립트는 아닙니다.

Admin·Client의 `log-generator-scripts` 대상에서 승인해 실행합니다. 모의 장애 전용이고 입력한 문장이나 명령 인자를 실행하지 않습니다. 파일을 수정하려면 검토 후 카탈로그의 SHA-256도 갱신해야 합니다. 변경된 정책은 이전 영수증으로 복구를 확인할 수 없으며 기존 실행 ID는 다시 실행하지 않습니다.
